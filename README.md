# Suman Patari — Portfolio

A fully static portfolio built with HTML, CSS, and JavaScript. It works without a build step and is ready for GitHub Pages.

## Update links

Edit `config.js` to add or change social and project URLs.

## Preview locally

Open `index.html` directly, or run any local static-file server from the repository root.

## Deploy with GitHub Pages

1. Push the repository to GitHub on the `main` branch.
2. Open **Settings → Pages** in the GitHub repository.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The included workflow publishes the portfolio automatically.

The gallery placeholder is a separate static site inside `gallery/`. Its link works both locally and when the portfolio is hosted under a GitHub Pages repository path.
